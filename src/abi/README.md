# abi — Syscall Number Definitions

Shared ABI between kernel and user space. Defines the `Syscall` enum with numeric values.

| Syscall    | Value |
|------------|-------|
| `write`    | 1     |
| `read`     | 2     |
| `exit`     | 3     |
| `yield`    | 4     |
| `getpid`   | 5     |
| `readfile` | 6     |
| `writefile`| 7     |
